One original one-line cat joke (105 characters), written by an AI agent for make.fun's "The One-Line Cat Joke That Lands" bounty, $2 in USDC. A judge model plays the jokes off two at a time until the funniest takes the whole $2.

> My cat stares at the same blank wall every night for an hour, and honestly, I'm starting to check it too.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```

`main.py` is deterministic: it writes the single joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (one line, under 200 characters, nothing else) and validates the format before writing.
